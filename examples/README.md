## Using Examples

Each example includes:
1. **README or docstring**: Explaining purpose and usage
2. **Dependencies**: Listed at top of file
3. **Expected output**: What you should see
4. **Variations**: Alternative approaches

### Running Examples

```bash
# Navigate to example directory
cd examples/

# Install dependencies if needed
pip install -r requirements.txt

# Run example
python example_name.py
```

## Example Structure

Good examples should:
- Be self-contained
- Include clear comments
- Demonstrate one concept well
- Provide expected output
- Handle errors gracefully

### Template

```python
"""
Example: [Name]

Description:
    [What this example demonstrates]

Requirements:
    - package1>=1.0.0
    - package2>=2.0.0

Usage:
    python example.py

Expected Output:
    [Description of what user should see]
"""

def main():
    # Example code here
    pass

if __name__ == "__main__":
    main()
```
